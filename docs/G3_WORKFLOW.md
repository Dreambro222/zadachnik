# G3 Workflow for Zadachnik

Этот документ фиксирует практику работы с `g3` в текущем проекте.

## Quick Start

```bash
cd "/Users/cek/Desktop/Задачник"
g3
```

После запуска используйте формат:

```text
requirement> <новое требование>
```

Каждый новый `requirement>`:
1. Добавляется в накопленные требования текущей сессии.
2. Автоматически запускает автономный coach-player цикл.
3. Вносит изменения итеративно, с учетом предыдущих требований.

## Пример

```text
requirement> create a simple web server in Python with Flask
requirement> add a /health endpoint that returns JSON
```

Во второй итерации агент работает уже с двумя требованиями одновременно.

## Рекомендуемый процесс для проекта

1. Перед новой сессией убедиться, что рабочее дерево чистое или есть snapshot.
2. Давать требования маленькими шагами (одна логическая задача за итерацию).
3. После каждой итерации:
   - проверить изменения файлов;
   - запустить сборку/приложение;
   - зафиксировать важные параметры в `PARAMS.md`;
   - при необходимости добавить выводы в `LESSONS.md`.
4. Для сложных задач сначала дать требование на план, затем отдельное требование на реализацию.
